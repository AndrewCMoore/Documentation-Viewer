# Welcome

This is a docs viewer for project documentation. It lists every `.md` file in
this repo automatically, at any depth — no build step.

## Adding a new doc

- A `.md` file at the repo root (like this one) is a root doc.
- A `.md` file in a subfolder (e.g. `smartsaver/...`) groups under a section
  named after that top-level folder — nest it as deep as you like.
- Commit and push, then refresh — it appears in the sidebar.
